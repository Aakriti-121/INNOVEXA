# INNOVEX

## AI Student Academic Support System

INNOVEXA is an AI-powered platform that helps students understand their academic performance and improve their studies.

The system analyzes:
- Subject-wise marks
- Attendance
- Previous academic performance

Based on the data, it identifies weak areas and provides an academic risk level such as **Low, Medium, or High Risk**.

##  Key Features

-  Academic performance analysis
-  Weak subject/topic identification
-  Risk prediction
-  Personalized study recommendations
-  Student-focused study planning

##  How It Works

Student Data → Backend API → AI/ML Analysis → Risk Prediction → Personalized Study Plan

##  Technology Stack

- **Frontend:** HTML, CSS, JavaScript, React
- **Backend:** Python / Node.js
- **Database:** SQL
- **AI/ML:** Python, Machine Learning
